# Miniread 更新记录

## V2.1（当前版本）

> 主题：书架组织能力 —— 搜索、分组、RSS 订阅

### ✨ 新增

#### 书架搜索
- 首页顶部新增搜索框，300ms 防抖实时过滤书架内容（标题/作者，不区分大小写），清空自动恢复
- 管理员额外显示「账号」分区：搜索匹配用户名，点击跳转后台用户管理
- 搜索无结果时显示空态提示

#### 分组管理（文件夹机制）
- 「上传书籍」按钮升级为「添加」主按钮，点击向下展开：上传书籍 / 新增分组 / 添加RSS订阅
- 新增分组：命名后出现在书架，封面为组内前 4 本书封面的 2×2 网格（不足补主题色块，空分组显示文件夹图标）
- 右键（桌面）/ 长按 500ms（移动端）卡片 → 「加入分组」：弹窗单选分组后即时移动，支持「不分组」移回根层级
- 多选模式：菜单「多选」进入复选界面，底部浮动操作条支持批量删除（二次确认）与批量移动至分组
- 点击分组卡片进入组内视图（文件夹机制），左上角返回上一级；删除分组时组内内容自动回到未分组
- 移动端完整支持：长按呼出与桌面右键一致的菜单，滑动自动取消

#### RSS 订阅
- 「添加RSS订阅」粘贴链接自动解析站点标题作为默认名称，可设置显示名称与同步间隔（小时，默认 24，无上限），确定后立即抓取一次
- RSS 在书架上与普通书同样呈现：卡片、右键属性、封面上传、加入分组一应俱全
- 点击卡片进入阅读视图：文章按发布日期从新到旧排序、按天显示日期分隔条（今天/昨天/M月D日）、无限向下滚动（每页 20 条）、点击条目平滑展开正文
- 正文入库前自动净化（移除 script/iframe/事件属性/javascript: 协议/内联颜色），暗色主题下文字颜色强制跟随主题，彻底解决"黑底黑字"问题
- 后台同步线程每 30 分钟扫描到期订阅自动同步（guid 去重）；属性弹窗可手动「立即同步」并显示上次同步时间与文章总数
- 支持自定义上传封面

#### 其他
- 版本号更新至 V2.1，服务横幅 / 后台 / 更新检查同步显示
- 兼容版（/old）书架层与标准版共享实现，全部新功能自动同步

## V2.0

> 主题：平台整体重建 —— 双版本前端、全格式阅读引擎、内容运营与运维能力

### ✨ 新增

#### 双版本前端
- 全新现代版界面 + 兼容版（`/old`）双实现，兼容 Chrome 91+ 内核浏览器，不依赖任何前端框架
- 全站亮色 / 暗色双主题，PC / 平板 / 手机全响应式
- 全新落地页（墨水时间线设计），未登录访客可浏览站点介绍与公告

#### 全格式电子书阅读
- **规范书管线**：TXT / EPUB / DOCX / FB2 / HTML / MD / RTF 上传后统一转为规范书存储（manifest + 章节 HTML + 资产），目录智能识别（中英文章节正则、EPUB 导航过滤、无章节书籍自动分块）
- **滚动 / 翻页双模式**：文字书可自由切换上下滚动与左右翻页（Foliate 分页引擎），设置按书记忆
- **PDF 阅读器**：IntersectionObserver 窗口化渲染（±2 页预载）、缩放、适应宽度/页面、旋转、移动端捏合缩放与双击放大、可折叠工具栏
- **PPT/PPTX**：上传后后台 LibreOffice 转 PDF 阅读；LibreOffice 不可用时回退浏览器端原生渲染（PptxViewJS）
- **原生格式**：MOBI / AZW / AZW3 / PRC / CBZ 由 Foliate 引擎直接打开
- **进度记忆**：文字书按章节+偏移、EPUB 按 CFI、PDF/PPT 按页码；标题可见自动推进章节进度，重开自动恢复位置
- **书签与标注**：书签添加/重命名/删除，选中文字高亮收藏

#### 公告系统
- Markdown 编辑器 + 实时预览，支持图片上传（自动转 WebP）与视频上传（自动转 MP4，ffmpeg）
- 按用户组可见（未登录 / 已登录 / 全部）、发布 / 草稿切换、拖动排序、不再提示记忆（按修改时间失效）
- 公告以响应式浮窗呈现（登录用户在书架弹出，访客在落地页弹出）；删除/编辑公告时自动清理孤儿媒体文件

#### 管理与运维
- **用户管理**：列表、封禁（强制下线 + IP 封锁 5 天）、解封、永久删除（附原因公告）、完整封禁日志
- **邀请码系统**：注册限制开关、批量生成（使用次数 / 有效期 / 备注）、单个编辑与批量删除
- **维护模式**：全站维护页（Markdown 公告），仅管理员可登录
- **在线更新**：GitHub Release 版本检查、在线下载安装、升级进度页，更新期间普通用户自动跳转
- **ZIP 备份/恢复**：一键导出（SQLite 数据库 + secret_key + uploads + 规范书目录），支持完整恢复；导入含路径穿越防护

#### 搜索下载（SoNovel 集成）
- SoNovel 服务器地址与 Token 配置
- 书籍搜索、EPUB/TXT/HTML/PDF 多格式下载、SSE 实时进度浮窗、下载完成自动入库

#### 阅读体验细节
- 阅读设置全量可调：字号、行高、段距、字距、词距、页边距、两端对齐、首行缩进、字体（衬线/无衬线/等宽）、主题预设（纸/羊皮/灰/石板/墨）、文字颜色（预设 + 自定义取色）
- 目录侧边栏点击精确跳转章节
- 转换遮罩：PPT/PPTX 后台转换时书架卡片模糊 + 提示，完成后自动恢复

### 🔧 优化
- SQLite WAL 模式提升并发读写
- 幂等数据库迁移模式（旧库升级自动补列，无需手动操作）
- 静态资源协商缓存（代码更新即时生效）
- 进度保存 sendBeacon 通道（页面关闭也能可靠落库）

### 🐛 修复（节选）
- 侧边栏目录点击不跳转（foliate 索引精确跳转 + 滚动引擎章节定位）
- 翻页模式切换后不生效（设置抽屉事件绑定链崩溃）
- PPT 旋转后比例错乱、内容过小（恒定宽高比 + 旋转补偿 + 动态适配）
- 公告视频上传 500、导出文件扩展名错误等
